托管按钮 managed / pm2
  • 适用场景：长期常驻 Web 服务（如 python server.py、npm run dev）。
  • 启动效果：PM2 托管并在后台常驻，自动拉起与守护。
  • 停止方式：启动后按钮自动变成 [■ 停止]，点击即调用 pm2 stop。
  • 最佳实践：只需建一个启动按钮，不需要另建停止按钮。
执行按钮 exec / subprocess
  • 适用场景：一次性脚本、构建打包、测试、或专用的停服脚本（如 catalina.sh stop）。
  • 启动效果：单次触发执行，标准输出实时流入抽屉。
  • 停止方式：跑完自动退出；若中途死循环或卡死，点 [⏹ 终止] 强行杀死。
  • 最佳实践：传统服务的启动和停止（如 Tomcat start/stop）都使用 exec 按钮。
